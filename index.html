ETAPA 01 · CONOCE LA HERRAMIENTA

¿Qué es el condicional SI?

FUNDAMENTOS

En programación, una condición permite que el algoritmo ejecute una instrucción solamente cuando se cumple algo.

?

1. Condición

Es una pregunta que puede tener dos respuestas: verdadero o falso.

→

2. Entonces

Indica qué instrucción debe ejecutar el algoritmo si la condición es verdadera.

✓

3. FinSi

Marca el final de las instrucciones que dependen de esa condición.

EJEMPLO EN PSEINT01 / CONDICIONAL SIMPLE
Algoritmo VerificarEdad
    Definir edad Como Entero
    Escribir "Ingrese su edad:"
    Leer edad

    Si edad >= 18 Entonces
        Escribir "Puedes votar"
    FinSi
FinAlgoritmo
ⓘ Si la edad es 18 o más, se muestra el mensaje. Si la condición es falsa, el algoritmo simplemente continúa; no muestra otro mensaje.
Operadores que puedes utilizar:> mayor que< menor que>= mayor o igual<= menor o igual= igual<> diferente
